Jalankan Local LLM Langsung di Vercel

Model GGUF open-source dijalankan langsung di dalam Serverless Function Vercel menggunakan llama.cpp CPU SIMD tanpa API key eksternal, dan dapat diakses publik melalui Web UI maupun REST API.
